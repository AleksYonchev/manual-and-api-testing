# Manual Web Testing

This folder contains my manual functional test work for the **Movie Catalog** educational web application, completed during SoftUni QA training.

## Tested features

- Landing page and navigation
- User registration
- User login
- Profile management
- Adding movies
- Viewing and managing movies

## Test documentation

The workbook contains written test cases, execution results, and bug reports based on observed application behavior. The test design includes positive and negative scenarios. Where applicable, failed tests are associated with a recorded defect.

**File:** [MovieCatalog_Manual_Testing.xlsx](MovieCatalog_Manual_Testing.xlsx)

**Note:** The complete test cases and bug reports are available in the Excel workbook. Download the file to review the original test documentation and execution results.

## Context

Movie Catalog and its functional requirements were provided for the course examination. The test cases and defect documentation are my own work. The original exam document is not included.

Bug priority and severity are historical student assessments, not production incident classifications or independently revalidated ratings.
